# Reference App → MetroLens AI Mapping Matrix

| Reference Pattern | MetroLens AI Equivalent | What Was Preserved | What Was Changed | Why It Was Changed (KMRL Domain Rationale) |
| :--- | :--- | :--- | :--- | :--- |
| **Generic PDF Summarizer / Chatbot View** | **Cross-Document Entity & NLP Intelligence Engine** | Clean multi-format document upload, OCR/text extraction viewer. | Replaced conversational generic chat with structured entity extraction (Station, Asset, Dept, Failure Mode, Date, Severity). | Transit engineers need structured data parameters for work orders, not casual conversational summaries. |
| **Isolated File List / Folder Hierarchy** | **Recurring Issue Cluster Matrix & Graph** | Tabular listing and metadata sorting. | Aggregates disparate documents into cohesive recurring incident clusters using semantic cosine similarity and asset-code alignment. | Individual logs mask systemic recurring failures. Connecting logs reveals chronic hardware defects. |
| **Basic Threshold Alert Banner** | **Silent Risk Radar (Emerging Weak Signal Engine)** | Alert notification system. | Added multi-factor weighted scoring combining low-severity complaints with maintenance logs and accelerating temporal frequency. | Disasters and major metro outages often begin as multiple unnoticed minor anomalies across different departments. |
| **Static Document Metadata Table** | **Interactive Asset Issue Progression Timeline** | Chronological record display. | Transformed static dates into an interactive event-chain timeline showing symptom escalation over weeks/months. | Enables root-cause investigators to track the exact lifecycle of an equipment degradation pattern. |
| **Standard Kanban / Task List** | **Human-in-the-Loop Action Center** | Status columns (New, In Progress, Resolved). | Integrated direct source document attribution, AI verification toggles, and department routing. | Ensures operators maintain final governance over AI recommendations with clear accountability. |
| **Opaque Confidence Metric (e.g., "94% Match")** | **Transparent Explainable AI (XAI) Inspector** | Visual score indicators. | Explicitly details mathematical factors: asset repetition count, station co-occurrence, velocity acceleration, and exact document excerpt citations. | Critical infrastructure authorities cannot trust black-box AI scores without auditable reasoning. |
| **Single English Interface** | **Full English & Tamil Localization Engine** | Clean typographic hierarchy. | Complete runtime i18n support (`en.json`, `ta.json`) without page reload. | Supports diverse regional operational staff and multi-lingual transit workforce across South Indian transport hubs. |
| **Standard Demo Sandboxing** | **3-Minute SIH Hackathon Interactive Demo Tour** | Guided sample workflows. | Pre-configured realistic KMRL synthetic incident scenarios (Escalator failure, AFC gate lags, Track signalling jitter) with 1-click execution. | Optimizes hackathon judging experience, demonstrating end-to-end value within a 3-5 minute presentation window. |
